넷플릭스 영상화는 원작 게임 IP의 이용을 늘렸을까?

게임을 원작으로 한 영상이 넷플릭스에 공개되면 원작 게임에 대한 관심(구글 검색량)과 실제 플레이(Steam 동시접속)가 늘어나는지 확인했습니다. 비교 기준은 공개 전 흐름이 그대로 이어졌다면 나왔을 값, 곧 기준선입니다. 아래 조절판에서 변수를 바꾸면 브라우저가 모델을 그 자리에서 다시 계산합니다.

3. 우리가 재는 것: 영상의 영향

영상의 영향 = 공개 후 실제값 − 기준선 (기준선: 공개 전 흐름이 그대로 이어졌다면 나왔을 값 · 인과를 확정한 값은 아닙니다)

게임 이용은 영상과 상관없이 계절, 업데이트, 할인 때문에도 오르내립니다. 공개 전후를 단순 비교하면 이런 변화까지 영상 덕분으로 읽게 됩니다. 그래서 공개 전 흐름으로 기준선을 만들고, 실제가 기준선보다 얼마나 많았는지만 영상의 영향으로 봅니다.

6. 계절을 빼도 결론이 같은가: 기본 모델과 보정 모델 비교

계절 변화를 빼고 다시 계산해도 11편 중 10편은 결론이 같았습니다(검색량·기본 설정).

단순 기준과 비교(기본 설정): 공개 직전 값을 그대로 이어 가는 가장 단순한 기준선과 견줘 봤습니다. 검색량은 단순 기준 16.0% 대 기본 모델 16.4%로 단순 기준이 0.4%p 더 정확합니다(거의 같은 수준), Steam은 단순 기준 24.4% 대 기본 모델 23.2%로 기본 모델이 1.2%p 더 정확합니다. 기본 모델은 복잡하게 맞춘 모델이 아니라 단순 기준과 비슷한 수준의 기준선입니다.

평소 예측 정확도(백테스트)

영상이 없던 시기에 같은 방법으로 예측했을 때의 평균 절대 오차입니다. 작을수록 정확합니다. α와 효과 기간을 바꾸면 다시 계산됩니다.

표 설명

두 모델이 평소에 얼마나 잘 맞히는지 비교합니다. 영상이 없던 시기에 수백 번 예측해 보고 평균적으로 몇 % 틀렸는지 적었습니다. 숫자가 작은 모델이 더 믿을 만해서, 판정은 기본 모델로 합니다.

    용어와 모델링 설명

    조절판의 각 항목이 무슨 뜻이고, 모델링에서 어떤 역할을 하는지 정리했습니다.

    모델링 전체 흐름

    1. 공개 전 흐름이 그대로 이어졌다면 공개 후 값이 얼마였을지 예측해 기준선을 만듭니다.
    2. 공개 후 실제값과 기준선의 차이를 효과(영상의 영향)로 잽니다.
    3. 영상이 없던 시기에 같은 계산을 수백 번 반복해 평소 오차를 만듭니다.
    4. 효과가 평소 오차보다 확실히 크면(p값이 판정 기준보다 작으면) "평소 변동 초과"로 판정합니다.

    조절판 항목

    지표
    뜻: 무엇으로 원작 게임의 반응을 잴지 고릅니다. 검색량은 구글 트렌드의 게임 주제 검색량(주별, 관심), Steam은 월평균 동시접속자(PC 플레이)입니다.
    역할: 모델이 예측하고 비교하는 대상 값입니다. 관심이 늘었는지, 실제 플레이가 늘었는지를 따로 볼 수 있습니다.
    모델: 기본(지수평활)
    뜻: 공개 직전까지의 값을 최근일수록 무겁게 평균 내서, 그 수준이 공개 후에도 그대로 이어진다고 보는 예측 방법입니다.
    역할: 기준선을 만듭니다. 영상이 없던 시기의 예측 오차가 가장 작아서 판정의 기본 모델로 씁니다.
    모델: 보정(계절·공통 변화)
    뜻: 기본 기준선에 평소에도 생기는 변화를 더한 예측입니다. Steam은 전년 같은 달의 변화(할인 달 상승, 8월 하락 같은 계절성), 검색량은 같은 주 다른 게임 검색어들의 공통 변화를 더합니다.
    역할: "효과처럼 보인 것이 사실 계절 때문은 아닌지" 확인합니다. 결론을 내는 모델이 아니라 점검용입니다.
    평활 강도 α
    뜻: 0.1~0.9 사이 값입니다. 클수록 공개 직전 몇 주의 값을 더 크게 반영하고, 작을수록 긴 기간의 평균에 가깝게 예측합니다.
    역할: 기준선의 높이를 정합니다. 공개 직전에 이미 오르던 작품은 α가 클수록 기준선이 높아져 효과가 작게 잡힙니다. 기본값은 0.5입니다.
    검색량 효과 기간
    뜻: 공개 후 몇 주의 평균으로 효과를 잴지 정합니다(2·4·6·8주).
    역할: 짧게 잡으면 공개 직후의 반짝 반응이, 길게 잡으면 오래가는 효과가 잘 보입니다. 기본값은 4주입니다.
    Steam 효과 기간
    뜻: Steam 자료는 월 단위라, 공개 후 28일이 가장 많이 걸친 달부터 몇 개월을 볼지 정합니다(1·2개월).
    역할: 검색량 효과 기간과 같은 역할을 월 단위로 합니다. 기본값은 1개월입니다.
    판정 기준 p <
    뜻: p값은 "영상이 없던 시기에도 이만한 차이가 날 확률"입니다. 판정 기준은 이 확률이 얼마보다 작아야 "평소 변동 초과"로 볼지 정하는 문턱입니다.
    역할: 0.01이면 엄격하게, 0.10이면 느슨하게 판정합니다. 기본값 0.05는 "평소라면 20번에 1번도 안 나올 차이"라는 뜻입니다.
    작품 범위
    뜻: 수업 Top 10 기간(2021.07~2022.01)에 공개된 14편, 그 밖의 비교 작품 6편, 전체 20편 중 무엇을 볼지 고릅니다.
    역할: 결론은 수업 기간 14편으로 내고, 기간 밖 6편은 비교용으로 따로 봅니다.

    결과에 나오는 용어

    효과(%)
    효과 기간 동안 실제가 기준선보다 몇 % 많았는지(음수면 적었는지)입니다. 이 보고서에서 말하는 "영상의 영향"입니다.
    평소 오차
    영상이 없던 시기에 같은 방법으로 예측했을 때 틀린 정도입니다. 효과가 "큰지 작은지"를 판단하는 잣대입니다.
    90% 신뢰구간
    평소 오차를 감안할 때 실제 효과가 있을 법한 범위입니다. 0을 가로지르면 실제로는 늘지 않았을 가능성도 남아 있습니다.
    평소 변동 초과 / 평소 범위
    p값이 판정 기준보다 작으면 "평소 변동 초과", 크면 "평소 범위"입니다.
    근거 강도
    검색량·Steam 두 지표와 기본·보정 두 모델 결과를 합친 판정입니다. 강함(두 모델 모두 초과, 주의 사항 없음), 보통(초과했지만 주의 사항이 있거나 보정 모델을 계산할 수 없음), 약함(한 모델만 초과), 효과 확인 안 됨(둘 다 평소 범위)으로 나눕니다.
    평소 예측 정확도(백테스트)
    영상이 없던 시기에 예측해 본 평균 절대 오차입니다. 작을수록 그 모델의 예측이 믿을 만합니다.
